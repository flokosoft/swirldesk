# MATRIX v0.7.0 — Digital Rain / Phosphor (TEST)

User confirmed the previous MATRIX appearance/functionality broadly, but found the Hyprland theme too close to FIELD. Redesign only the MATRIX Hyprland appearance, not Plasma or any other theme. Baseline: cumulative 0.1.0–0.5.0 Hyprland overlays plus 0.6.0 Plasma overlay. No new dependencies, fonts, services or packages. No forced tray icon override.

## Install / restore
Extract the archive into ~/.config/swirldesk, then `bash matrix-support/enable-digital.sh` and reselect MATRIX using Super+Shift+T in Hyprland. The archive itself does not overwrite the live theme. The installer uses a manifest of known original and new file hashes, refusing the entire operation on an unknown/customized file or missing prerequisite. It preserves permissions and replaces individual files atomically. Original versions are included for exact rollback. Run `python3 matrix-support/digital/manage.py doctor` to check the installed files and `bash matrix-support/doctor.sh` for the established theme diagnosis. To restore the original appearance: `bash matrix-support/disable-digital.sh`, then reselect MATRIX. Do this before using older session or icon rollback scripts, whose integrity checks expect the earlier configurations. Do not remove the digital support directory before rollback. No user state is shipped or overwritten.

## Changes
- Floating/inset Waybar data strip, workspace group centered where space permits, lowercase status labels, no tactical separators, solid phosphor active workspace. All existing modules, exec commands and mouse handlers retained. Waybar 0.12 supports margins and center modules (Debian trixie waybar(5)).
- 1px phosphor borders, 5px corner radius, gaps 9/12, slightly revised pop-in and workspace animations; unchanged dwindle layout, existing rules and keybindings. No blur or animation daemon.
- Terminal padding, palette, prompt and Fastfetch binary-code branding; launcher and notification visuals; less boxed GTK console sections, quieter GTK application surfaces. Existing power actions and confirmation logic unchanged; fallback labels changed consistently.
- Dark native Hyprlock with clearer film-inspired text, existing authentication unchanged. Three wallpaper profiles and wallpaper assets untouched (including soft CONSTRUCT).
- Existing icon theme, tray configuration and other themes unchanged. Native app pixmaps may still appear blue/colorful. Existing shared theme-switcher, controls, telemetry sampler and plasma files are unchanged.

The operator console now calls Gtk.ScrolledWindow.set_overlay_scrolling(False) and reserves a 12-logical-pixel end margin on the content box. The scrollbar has its own layout space when needed; no global GTK setting is changed. The 0.7.0 hash is accepted during apply/restore, while restore still returns to the original pre-0.7 appearance. Extract the complete digital overlay, run enable-digital.sh, then close and reopen the Control Center. No theme reload is required when upgrading from 0.7.0.
