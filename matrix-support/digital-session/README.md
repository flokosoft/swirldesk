# MATRIX v0.9.0 TEST — Digital Session (Hyprland)

Requires the installed v0.8.2 chain (especially Digital Appearance 0.7.1). Install overlay and run `bash matrix-support/enable-digital-session.sh`; reselect MATRIX to reload Waybar. No bundled fonts, root actions, system unit, display manager, PAM, Hypridle, Hyprlock, shared scripts, or Plasma edits.

Control Center → digital session (Fuzzel menu), or `themes/swirldesk-matrix/session/digital/ctl.sh menu`. Intro defaults on, once per compositor instance on the first MATRIX Waybar status poll (also when first selected in an existing session), ~5s. Logout animation defaults on, ~2.5s, only after confirmation through MATRIX session menu; failed visuals must not block logout. Optional low-volume original local WAV, sound off by default, paplay needed. Screensaver defaults off; choose 60/180/300 seconds; only on confirmed external power. Preview is bounded to 8s, also possible on battery. `swayidle` from Debian is optional; the process only receives timeout/resume commands with isolated empty config. No security or display-power actions. Existing Hypridle continues locking and powering off monitors independently (uploaded base defaults 600/900s; local settings may differ). Automatic idle visuals stop on input/lock/theme/battery; click or key can reach the underlying app because visual overlay is intentionally input-transparent. Do not treat this as a lock. Existing lock shortcut remains the safe way to leave device unattended. Intro/exit visuals also do not grab input. Rendering uses GTK3 layer shell and reuses rain simulation, 10 FPS target; no live performance measurements. Screensaver cap 420s per idle event. Existing rain and CRT settings remain independent and unchanged.

`bash matrix-support/session-doctor.sh` checks integration and dependencies; state file `state/matrix_digital_session.json`; session-specific runtime status/log under `$XDG_RUNTIME_DIR/swirldesk-matrix-session-*`. If no swayidle, `sudo apt install swayidle` is optional and user-initiated. If no paplay, `sudo apt install pulseaudio-utils` optional. Gtk dependencies same as rain. Missing dependencies do not alter lock or log out logic. `bash matrix-support/disable-digital-session.sh` restores exact v0.8.2 files; reselect MATRIX. Disable this extension before older digital appearance rollback or reinstalling older overlay. Preference file kept. Installer refuses locally modified managed files; no writes to those files on mismatch. The overlay contains new assets and integration templates only.

Tests: reconstructed v0.8.2 install, guarded apply/reapply/restore and local customization refusal, digital appearance doctor before/after, nine policy/unit tests, six CRT and five rain regression tests, shell/Python/JSON syntax. Live GTK layer shell, idle events and wake-up, real Hyprlock/DPMS and sound not tested here. User confirmed 0.8.2 shader works. Next: live test, integration polish 0.9.1, complete font-free master package 1.0.0.
